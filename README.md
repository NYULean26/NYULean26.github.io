# Computer-Assisted Formalization of Mathematics

Course website for **Computer-Assisted Formalization of Mathematics**, taught at New York University in Fall 2026.

- DS-GA 3001 · Section 007: Special Topics in Data Science
- MATH-GA 2650: Advanced Topics in Analysis
- Instructor: Jaume de Dios Pont

## Preview locally

The site has no build step. From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Update the site

Course content lives in `index.html`, visual styles in `assets/styles.css`, and the small navigation/reveal enhancements in `assets/script.js`. Relative asset paths keep the site compatible with a GitHub Pages project URL.

Pushing to the `main` branch automatically republishes the GitHub Pages site from the repository root.
